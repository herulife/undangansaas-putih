## Ringkasan fitur per kategori (frekuensi di pasar)

Fitur yang hampir universal (>80% platform):
- Custom nama tamu, countdown, detail acara, Google Maps, galeri foto/video,
  background music, love story, ucapan/buku tamu, RSVP, amplop digital, quotes/doa.
- Masa aktif: banyak menawarkan "selamanya".

Fitur pembeda (differentiator) yang makin jadi standar di 2026:
- **QR check-in + guest on screen** di venue (Wedew, InviteAnywhere, Akuakad, Abadikan, Invitera).
- **Blast WhatsApp otomatis** (Wedew pakai API resmi; lain pakai gateway).
- **Import CSV + link personal + tracking dibuka** (Suratan).
- **Export Excel/CSV/PDF** (undangandigital.io, Akuakad).
- **Meja/seating, kode souvenir, nomor angpao** (InviteAnywhere).
- **Angpao QRIS + dompet digital pengantin** (Akuakad, Invitera).
- **Editor drag & drop** (Akuakad).
- **Filter ucapan negatif otomatis** (Wedly).
- **Multi-bahasa + Google Calendar** (undangandigital.io).
- **Live streaming embed** (banyak).
- **Auto twibbon** (InviteAnywhere).
- **Wedding planner add-on** (Seundang).
- **White-label / custom domain / reseller** (Invi.id, Undangan.One, Invitation.id).

## Model monetisasi yang dipakai pasar

1. **Freemium** → gratis 1 undangan, bayar untuk premium/tanpa watermark.
2. **One-time / paket masa aktif** → paling banyak; "aktif selamanya" jadi magnet.
3. **Add-on** → wedding planner, WhatsApp blast credit, custom domain, express.
4. **Reseller/Affiliate** → beli kuota client, komisi hingga 40–50%.
5. **White-label / B2B** → EO, vendor, instansi (Invi.id reseller, Invitation.id Premium+).
6. **Langganan bulanan/tahunan** → mulai jarang untuk end-user, masih untuk B2B/agency.

## Catatan strategis untuk linkundang.web.id

- Pasar sudah penuh fitur dasar → keunggulan harus di **manajemen tamu + operasional hari-H** (tracking, blast WA, QR check-in, seating) dan **kecepatan setup self-service**.
- Harga pasar: entry Rp30–50k, sweet spot Rp79–149k, premium Rp199–499k, custom Rp799k+.
- Peluang diferensiasi: **reseller/B2B** + **white-label** + **AI** (generate ornamen/foto, yang sudah dimiliki proyek ini) jarang digarap pesaing kecil.
