## Naming Rule

Gunakan pola:

```text
{kategori}-{kode/template-dna}-{gaya/tema}-{nama-pasangan-atau-status}
```

Contoh:

```text
adat-jawa-050-klasik-alyssa-rayhan
wedding-premium074-indonesia-editorial
```
