# Public Template Assets

Folder ini adalah asset yang disajikan Vite sebagai URL `/template-assets/...`.

Nama folder disamakan dengan source template di `D:/UNDANGAN/template` jika template tersebut aktif di registry. Folder tambahan seperti `wedding-premium050-original`, `wedding-premium050-pro-clean`, dan `adat-sunda-ai-generated-draft` disimpan sebagai referensi/eksperimen.

Jangan pakai nama angka saja untuk template baru. Gunakan nama deskriptif seperti:

```text
wedding-premium042-wayang-batik
adat-jawa-050-klasik-alyssa-rayhan
adat-minang-050-klasik-zahra-fadli
```
